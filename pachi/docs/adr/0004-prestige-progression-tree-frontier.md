# 4. Prestige Reset Loop and Progression Tree Frontier Drafting

We structure meta-progression around a Prize Meter that awards Prize Tokens on reset, with a Prestige Shop drafting cards and upgrades from the frontier of an incremental progression tree.

## Context & Trade-offs

Pachi combines incremental progression with deckbuilding mechanics. We needed a meta-progression loop that honors both genres without degenerating into an unguided random draft or a rigid static tree.

- We rejected a pure roguelike random card draft across the entire catalog. Unconstrained random card pools dilute archetypes and undermine long-term incremental scaling.
- We rejected a standard linear skill tree where players directly purchase static perks with zero deckbuilding elements. Linear trees eliminate drafting variety and player agency in shaping in-run draw odds.
- We chose progression tree frontier drafting with booster packs and open upgrades. Unlocked progression nodes define the available draft frontier. Buying node upgrades can add card copies to the Master Deck, boost card baseline stats, or unlock higher-tier card variants in the in-run shop.
