# Pachi Guidelines

## 1. Tech Stack & Environment
- **Engine**: Godot 4.7 (C# / Mobile target)
- **SDK & Runtime**: .NET 8.0 (`Godot.NET.Sdk/4.7.0`), Android build target `.NET 9.0`
- **Physics**: Rapier2D (`addons/godot-rapier2d`)
- **Solution**: `Pachi.sln` / `Pachi.csproj`

## 2. Structure & Conventions
- **Code Directory**: Source code organized by domain in `src/`
- **C# Scripts**: `PascalCase.cs` (e.g. [`PocketBallsIndicator.cs`](file:///home/axel/workspace/axelmagn/pachi/pachi/src/pockets/PocketBallsIndicator.cs))
- **Godot Scenes**: `snake_case.tscn` (e.g. `pocket.tscn`, `main_game.tscn`)
- **UID Sidecars**: Preserve all `.cs.uid` files generated by Godot's UID system

## 3. Build & Verification Commands
- **Unified Verification Pipeline**: `./scripts/verify.sh` (Linux/macOS) or `.\scripts\verify.ps1` (Windows)
  - Runs 3 verification stages:
    1. C# formatting & style check (`dotnet format Pachi.sln --verify-no-changes`)
    2. Compiler & Roslyn analyzer verification (`dotnet build Pachi.sln` with `TreatWarningsAsErrors=true` and `AnalysisLevel=latest-recommended`)
    3. Headless Godot editor and test suite validation (`godot-mono --headless -s src/tests/TestRunner.cs`)
  - **Auto-Fix Formatting**: Run `./scripts/verify.sh --fix` or `.\scripts\verify.ps1 -Fix` (or `dotnet format Pachi.sln`) to automatically resolve formatting discrepancies.
- **Rules**:
  - Run `./scripts/verify.sh` (or `.\scripts\verify.ps1` on Windows) after any C# or scene edit before completing tasks.
  - Verification must pass with 0 errors and 0 warnings.
  - Skip verification commands when no code or scene files changed.

## 4. Coding Standards & Patterns
- **Nullable Reference Types**: `<Nullable>enable</Nullable>` is enabled project-wide with zero warning tolerance (`TreatWarningsAsErrors=true`).
  - Declare optional references as nullable (`Type?`).
  - For required `[Export]` node references or properties initialized in `_Ready()`, declare as `Type?` and assert non-null in `_Ready()` (e.g. `Debug.Assert(NodeRef != null)`), or use `= null!`.
- **Code Style & Formatting**: Enforced via `.editorconfig` (4 spaces, UTF-8, LF, Allman braces, PascalCase types/methods/properties, camelCase locals/parameters).
- **Partial Classes**: Godot C# scripts must be partial classes inheriting Godot nodes (e.g. `public partial class Pocket : Node2D`).
- **Attributes**:
  - `[GlobalClass]`: Custom node classes registered in Godot.
  - `[Tool]`: Editor-viewport scripts and custom `Resource` classes used by tool scripts.
  - `[Export]`: Inspector-exposed properties.
- **Redraw Property Setters**: In `[Tool]` scripts with `_Draw()`, use backing fields and call `QueueRedraw()` inside property setters. Reference: [`PocketBallsIndicator.cs`](file:///home/axel/workspace/axelmagn/pachi/pachi/src/pockets/PocketBallsIndicator.cs).
- **Node Validation**: Assert required `[Export]` node references in `_Ready()` using `Debug.Assert(...)`. Reference: [`Pocket.cs`](file:///home/axel/workspace/axelmagn/pachi/pachi/src/pockets/Pocket.cs).
- **Type-Safe API References**: Use source-generated `PropertyName` (e.g. `PropertyName.Scale`), `SignalName`, `nameof(...)`, or static `StringName` constants instead of string literals.
- **Lifecycle & Cleanup**: Unsubscribe (`-=`) from autoloads/singletons in `_ExitTree()`. For dynamic entities or single-use events, use `await ToSignal(...)` or `Connect(..., (uint)ConnectFlags.OneShot)`.
- **Async Signatures**: Return `async Task` or `async ValueTask` (avoid `async void`).

## 5. Engine Configurations & Guardrails
- **Physics Layer 2**: Designated for `"Ball"`.
- **Input Action**: `launcher_charge` (mapped to Spacebar).
- **Language**: C# only; avoid GDScript unless explicitly requested.
